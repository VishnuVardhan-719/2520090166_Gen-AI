# 2520090166 — Generative AI (Skills & Labs)

This repository contains weekly skill exercises and practical implementations for the Generative AI course.

## Repository Structure

```text
skills/
├── WEEK-1 LLM-CALL/   # Initial LLM API calls and prompt handling
└── WEEK-2 OLLAMA/     # Model clients and local/cloud inference (Ollama & Gemini)
```

## Getting Started

1. Navigate to the desired skill directory:
   ```bash
   cd "skills/WEEK-1 LLM-CALL"
   # or
   cd "skills/WEEK-2 OLLAMA"
   ```

2. Set up a Python virtual environment:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. Install required packages:
   ```bash
   pip install -r requirements.txt
   ```

4. Configure your environment:
   Copy `.env.example` to `.env` and fill in your API credentials.

5. Run the application:
   ```bash
   python main.py
   ```
